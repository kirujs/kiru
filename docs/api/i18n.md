# Internationalization

## Overview

Kiru provides locale-aware routing, message loading, URL prefix/domain policies, server-side locale detection, and per-locale SSG prerender expansion. Pass `i18n` config to `createRouterApp`, `createRenderer`, and `createKiruHandler`.

---

## How it works

### Configuration

`createI18nConfig` defines locales, default locale, message loaders, and routing policy:

```ts
const i18n = createI18nConfig({
  locales: ["en", "fr", "de"],
  defaultLocale: "en",
  load: {
    en: () => import("./i18n/en.json"),
    fr: () => import("./i18n/fr.json"),
    de: () => import("./i18n/de.json"),
  },
  routing: {
    prefix: "as-needed",  // "always" | "never" | "as-needed"
  },
  detection: {
    cookie: "locale",
    header: true,
  },
  domains: [/* optional per-locale hostnames */],
})
```

### Module augmentation

```ts
declare module "kiru/router" {
  interface Internationalization {
    config: typeof i18n
  }
}
```

Enables typed locale strings on `setLocale`, `Link`, and `navigate`.

### URL routing

| Policy | Behavior |
|--------|----------|
| `always` | Every URL has locale prefix (`/en/about`) |
| `as-needed` | Default locale omits prefix (`/about`); others prefixed (`/fr/about`) |
| `never` | No prefix; locale from cookie/header/domain only |

Helpers: `splitAppPathname`, `formatPublicHref`, `parseAppLocation`, `localePublicPath`.

### Translations in components

```tsx
import { useI18n } from "kiru/router"

export default function AboutPage() {
  const { t, locale } = useI18n()
  return () => <h1>{t("about.title")}</h1>
}
```

`I18nProvider` wraps subtrees; `createRouterApp` sets this up automatically when `i18n` is passed.

### Server detection

`detectLocaleFromRequest(request, config)` and `resolveLocale` pick the active locale on SSR first paint. Middleware can redirect to the correct prefixed URL.

### Hydration

Server embeds translation payload in `<script k-i18n>`. Client calls `ensureClientI18nReady(router)` before mount/hydrate. `serializeI18nScript` / `readHydratedI18n` handle the wire format.

### SSG per-locale HTML

`expandPrerenderTargets(paths, i18n)` and `expandPathsForLocales` duplicate static paths per locale. Each locale gets its own HTML file with correct `lang` attribute and messages.

### Navigation

```ts
router.setLocale("fr", { replace: true })
<Link to="/about" locale="fr">Français</Link>
router.navigate({ pathname: "/about", locale: "de" })
```

## API reference

```ts
import {
  createI18nConfig,
  useI18n,
  I18nProvider,
  createI18nTranslator,
  getByPath,
  formatPublicHref,
  splitAppPathname,
  parseAppLocation,
  detectLocaleFromRequest,
  resolveLocale,
  expandPrerenderTargets,
  expandPathsForLocales,
  ensureClientI18nReady,
  serializeI18nScript,
  readHydratedI18n,
  type InternationalizationConfig,
  type I18nTranslator,
} from "kiru/router"
```

```ts
type LocalePrefixPolicy = "as-needed" | "always" | "never"
type InvalidLocalePolicy = "redirect" | "not-found"

type InternationalizationConfig<Locales extends readonly string[], Data> = {
  defaultLocale: Locales[number]
  locales: Locales
  load: { [locale in Locales[number]]: () => Promise<Data> }
  localePrefix: LocalePrefixPolicy
  invalidLocale: InvalidLocalePolicy
  localeDetection: boolean
  localeCookie: string
  detectPaths: readonly string[]
  domains: NormalizedDomainEntry[]
}

type CreateI18nConfigInput<TLocales extends readonly string[], TLoaders> = {
  locales: TLocales
  defaultLocale: TLocales[number]
  load: TLoaders
  localePrefix?: LocalePrefixPolicy
  invalidLocale?: InvalidLocalePolicy
  localeDetection?: boolean
  localeCookie?: string
  detectPaths?: readonly string[]
  domains?: readonly I18nDomainInput[]
}

function createI18nConfig(input: CreateI18nConfigInput<...>): InternationalizationConfig<...>
```

Augment `Internationalization` so `useI18n()` and `RouterLocaleParam` are typed:

```ts
declare module "kiru/router" {
  interface Internationalization {
    config: typeof i18n
  }
}
```

## Examples

### Basic — two locales with JSON files

```ts
// i18n.ts
import { createI18nConfig } from "kiru/router"

export const i18n = createI18nConfig({
  locales: ["en", "fr"],
  defaultLocale: "en",
  load: {
    en: () => import("./i18n/en.json"),
    fr: () => import("./i18n/fr.json"),
  },
})

declare module "kiru/router" {
  interface Internationalization {
    config: typeof i18n
  }
}
```

```tsx
// main.tsx
import { createRouterApp } from "kiru/router/ssr"
import { i18n } from "./i18n"

void createRouterApp({ routes, container, i18n })
```

### Intermediate — translated page

```tsx
// pages/about.tsx
import { useI18n } from "kiru/router"

export default function AboutPage() {
  const { t } = useI18n()
  return () => (
    <main>
      <h1>{t("about.title")}</h1>
      <p>{t("about.description")}</p>
    </main>
  )
}
```

```json
// i18n/en.json
{ "about": { "title": "About us", "description": "We build tools." } }
```

### Intermediate — locale-prefixed Link

```tsx
import { Link, useI18n } from "kiru/router"

export default function Nav() {
  const { locale } = useI18n()
  return () => (
    <nav>
      <Link to="/" locale="en">EN</Link>
      <Link to="/" locale="fr">FR</Link>
      <span>Current: {locale.value}</span>
    </nav>
  )
}
```

### Advanced — domain-based locales

```ts
export const i18n = createI18nConfig({
  locales: ["en", "fr"],
  defaultLocale: "en",
  load: { en: () => import("./en.json"), fr: () => import("./fr.json") },
  domains: [
    { domain: "example.com", defaultLocale: "en", locales: ["en"] },
    { domain: "example.fr", defaultLocale: "fr", locales: ["fr"] },
  ],
})
```

### Advanced — SSG expands all locales

```ts
// Automatic when i18n is passed to createRenderer / vite ssg build
// expandPrerenderTargets turns ["/about"] into ["/about", "/fr/about"] with as-needed policy
```

```ts
import { expandPrerenderTargets } from "kiru/router"

const paths = generateStaticPaths(manifest)
const localized = expandPrerenderTargets(paths, i18n)
```

### Advanced — server + client i18n parity

```ts
// server.ts
createKiruHandler({ routes, i18n, getRequestContext })

// client.tsx
createRouterApp({ routes, container, i18n })
```

Both must use the same `i18n` config object shape and locale list.
