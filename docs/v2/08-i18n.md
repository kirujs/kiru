# Internationalization (i18n)

Locale-aware URLs, message bundles, SSR hydration, hreflang sitemaps, and hybrid domain routing. Implementation: `packages/lib/src/router/i18n/`.

## Config

```ts
// src/i18n.ts
import { createI18nConfig } from "kiru/router"

const i18n = createI18nConfig({
  locales: ["en-US", "fr", "nl-NL", "nl-BE", "de"],
  defaultLocale: "en-US",
  localePrefix: "as-needed",
  invalidLocale: "redirect",
  localeDetection: true,
  localeCookie: "KIRU_LOCALE",
  detectPaths: ["/"],
  domains: [
    { domain: "example.com", defaultLocale: "en-US" },
    { domain: "example.fr", defaultLocale: "fr" },
    {
      domain: "example.nl",
      defaultLocale: "nl-NL",
      locales: ["nl-BE"],
    },
  ],
  load: {
    "en-US": () => import("./i18n/en.json").then((m) => m.default),
    fr: () => import("./i18n/fr.json").then((m) => m.default),
    "nl-NL": () => import("./i18n/nl.json").then((m) => m.default),
    "nl-BE": () => import("./i18n/nl-BE.json").then((m) => m.default),
    de: () => import("./i18n/de.json").then((m) => m.default),
  },
})

export default i18n
```

`load` functions return the message object directly (unwrap JSON default exports in the loader).

### Routing policies

| Option | Behavior |
|--------|----------|
| `localePrefix: "always"` | `/en/about`, `/fr/about` (path-only locales) |
| `localePrefix: "as-needed"` | Default locale omits prefix where policy applies |
| `invalidLocale: "redirect"` | Unknown `/xx/...` → default or detect |
| `localeDetection` | `Accept-Language` / cookie on `detectPaths` |

Logical routes stay `/about` in `routes.ts`; router strips/adds prefix via `localeRouting.ts` + `splitAppPathname`.

### Domain routing (Next.js-style hybrid)

| Locale | Host | Public URL for `/blog` |
|--------|------|------------------------|
| `en-US` | `example.com` | `https://example.com/blog` |
| `fr` | `example.fr` | `https://example.fr/blog` |
| `nl-NL` | `example.nl` | `https://example.nl/blog` |
| `nl-BE` | `example.nl` + `locales` | `https://example.nl/nl-BE/blog` |
| `de` (not in `domains`) | `example.com` | `https://example.com/de/blog` |

- **`domains[].domain`** — hostname only; list subdomains explicitly (`www.example.com`). Apex `example.com` also matches `www.example.com`.
- **`defaultLocale`** on a domain — unprefixed paths on that host.
- **`locales`** on a domain — extra locales served on the same host with a path prefix.
- **Locale detection on `/`** — redirects to the domain that owns the detected locale (not only a path prefix).
- **`setLocale` / `Link locale=`** — same-origin when the host is unchanged; absolute URL when switching domains.
- **Cookies** — `KIRU_LOCALE` is per-host; not shared across registrable domains.

## Type-safe `useI18n`

```ts
declare module "kiru/router" {
  interface Internationalization {
    config: typeof i18n
  }
}
```

```tsx
const { t, locale, setLocale } = useI18n()
return () => <h1>{t("home.title")}</h1>
```

## Wiring per mode

```ts
createRouterApp({ routes, i18n, ... })
createRenderer({ routes, i18n, ... })
```

### SSR hydration

`serializeI18nScript` embeds active locale + messages in `<script k-i18n>`.

### CSR without SSR payload

`ensureClientI18nReady` awaits `i18n.load[locale]()` before mount when no `k-i18n` in document.

## `Link` locale prop

```tsx
<Link href="/about" locale="fr">Version française</Link>
```

Cross-domain locales resolve to absolute URLs automatically.

## Static paths + SSG

`expandPrerenderTargets` / `generatePublicStaticPaths` emit per-locale public paths. Domain-bound locales that share the same public pathname are written under `/.kiru-i18n/{locale}/...` on disk; production prerender serve resolves locale from the `Host` header.

## Site config + hreflang

Sitemap alternates use per-locale origins from `domains` when configured (`site.ts`).

## Loader context

When i18n is enabled, loaders receive `{ locale, locales, defaultLocale }`.
